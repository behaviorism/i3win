# Plan 8: Mouse Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move and resize windows with the mouse the i3 way (floating and tiled, `floating_modifier`, tiling drag with a drop preview, native title-bar and border drags), focus follows mouse, mouse warping, and wheel over tab rows.

**Architecture:** Geometry decisions (edge resize, drop zones, drop insertion, corner resize) are pure `Wm`/free functions in `i3win-core`. The platform adds a `WH_MOUSE_LL` hook on the main thread that only consults a thread-local snapshot of managed window rects (written each flush), decides swallow/pass, queues and posts; a drag state machine in `App` drives the core functions; a layered overlay window shows the drop target.

**Tech Stack:** Rust 2021, `windows` 0.58 (`Win32_UI_WindowsAndMessaging`, `Win32_Graphics_Gdi`, `Win32_UI_Input_KeyboardAndMouse`).

**Spec:** `docs/superpowers/specs/2026-10-17-i3win-v2-design.md` (section "Mouse" in full).

## Global Constraints

- Same as Plan 5's.
- The mouse hook runs on the main thread (LL hooks are called on the installing thread) and must: never allocate in the common path, never call into other processes (no `WindowFromPoint`, no `SendMessage`), return within microseconds. It reads only thread-local state written by the main thread.
- The hook swallows a button only when the `floating_modifier` is held and the press lands on a managed window (per the snapshot), or a drag it started is in progress. Everything else passes.
- Mouse moves are coalesced: one pending wake message at a time, latest position wins (the v1 `WAKE_PENDING` pattern). While no drag is active and `focus_follows_mouse` is off, moves are not posted at all.
- Tiled live resize re-arranges at most once per 16 ms.
- Hover focus never happens while a button is down, during a drag, when the foreground window is not managed, or over a bar; it requires the pointer to rest 50 ms on the new window.
- Defaults: `focus_follows_mouse yes`, `mouse_warping output`, `tiling_drag modifier titlebar`, `floating_modifier` none unless configured (Plan 5 parsed these).

## Review Focus

1. A modifier-click over a non-managed window (desktop, taskbar, Start menu, an elevated window we don't manage) passes through untouched (Task 4 test `press_outside_managed_passes`).
2. Releasing the modifier mid-drag keeps the drag going; only the button release ends it (Task 4 test `modifier_release_does_not_end_drag`).
3. Dropping a window onto itself or onto a floating/fullscreen window changes nothing (Task 2 test `drop_noop_cases`).
4. A native resize of a tiled window at the workspace edge snaps that edge back while the inner edge resizes (Task 6 test `native_resize_edges_from_rects`).
5. Hover focus does not fire while a context menu (unmanaged foreground) is open (Task 7 test `hover_blocked_when_foreground_unmanaged`).

    /// Walk up from node to the nearest ancestor whose layout is splith (Left/Right) or splitv (Up/Down)
    /// where the walked-up child has a sibling on that side (tabbed/stacked ancestors skipped);

    pub fn node_rect(&self, node: NodeId) -> Option<Rect>;

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum DropZone { Swap, Side(Direction) }
/// Center box (middle 30% of width and height) -> Swap; else the triangle formed by the rect's diagonals that contains the point.
pub fn drop_zone(r: Rect, x: i32, y: i32) -> DropZone;
#[derive(Clone, Debug, PartialEq)] pub enum DropTarget { Window(NodeId, DropZone), Workspace(String), Output(NodeId), Nothing }
impl Wm {
    /// Target under a screen point for a tiling drag of `dragged` (bar hits are resolved by the platform into Workspace).
    pub fn drop_target_at(&self, dragged: NodeId, x: i32, y: i32) -> DropTarget;
    /// Performs the drop; returns whether anything changed. Focus stays on `dragged`.
    pub fn drop_window(&mut self, dragged: NodeId, target: &DropTarget) -> bool;
    /// Rect to preview for a target (the zone's half/whole target rect, or the workspace area).
    pub fn drop_preview_rect(&self, target: &DropTarget) -> Option<Rect>;
}
```

- Rules (spec): Swap → `Tree::swap`. Side(d): remove `dragged` with v1 removal cleanup, then if the target's parent layout matches d's orientation (`splith` for Left/Right, `splitv` for Up/Down) insert as the target's sibling on that side; else wrap the target in a new container with the matching split layout (`Tree::wrap`) holding target and dragged in d's order. Target inside tabbed/stacked parent → insert as a new tab right after the target regardless of zone. Dragged == target, target floating, target fullscreen → no change (`drop_target_at` returns `Nothing` for them). `Workspace(name)` → move to that workspace (not following). `Output(o)` → move to that output's visible workspace, appended. `drop_target_at` ignores floating windows and picks the tiled window whose `node_rect` contains the point, on any output's visible workspace (the dragged window itself → `Nothing`); a point on an output but over no tiled window → `Output(o)`.
- Preview: Swap → the target rect; Side(Left) → left half of target rect, etc.; Workspace/Output → the workspace area rect.

#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Button { Left, Right, Middle }
#[derive(Clone, Copy, Debug, PartialEq)] pub struct Hit { pub id: WindowId, pub rect: Rect, pub floating: bool }
pub struct Snapshot { pub hits: Vec<Hit> /* topmost first: floating (last-focused first), then tiled */, pub modifier: Option<Modifiers>, pub want_moves: bool /* ffm on */ }
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum MouseEvent { Press { button: Button, x: i32, y: i32, id: WindowId }, Release { button: Button, x: i32, y: i32 }, Move { x: i32, y: i32 } }
pub enum MouseAction { Pass, Swallow }
pub struct MouseMatcher { /* snapshot, dragging: Option<Button>, held_mods source */ }
impl MouseMatcher {
    pub fn set_snapshot(&mut self, s: Snapshot);
    pub fn on_button(&mut self, button: Button, down: bool, x: i32, y: i32, mods: Modifiers) -> (MouseAction, Option<MouseEvent>);
    //   down: modifier present (all bits of snapshot.modifier in mods) and a hit contains (x,y) (Left/Right only) -> Swallow + Press{id}, dragging = Some(button);
    //   up: if dragging == Some(button) -> Swallow + Release, dragging = None; else Pass.
    pub fn on_move(&mut self, x: i32, y: i32) -> Option<MouseEvent>;   // Some(Move) iff dragging or snapshot.want_moves
    pub fn is_dragging(&self) -> bool;
}
pub fn install() -> windows::core::Result<()>;  pub fn uninstall();
pub fn set_snapshot(s: Snapshot);               // main thread, each flush
pub fn drain() -> (Vec<MouseEvent>, Option<(i32, i32)> /* latest coalesced move */);
// mainloop: WM_APP_MOUSE -> App::on_mouse(events, latest_move)
```

- Held modifiers come from the keyboard matcher (`keyboard::held_mods() -> Modifiers`, a new accessor over `KeyMatcher::mods()`), not `GetAsyncKeyState`.
- Press events carry the hit `id`; moves are coalesced into one "latest" slot plus a `MOUSE_PENDING` flag (post only if not already pending).
- The snapshot is built in `App::flush` from the arrangement (`windows` placements; floating ones first in focus order).

pub struct Drag { pub node: NodeId, pub kind: DragKind, pub origin: (i32, i32), pub last: (i32, i32), pub last_apply_ms: u64 }
pub fn start_drag(wm: &Wm, node: NodeId, button: Button, x: i32, y: i32, from_titlebar: bool) -> Option<Drag>
//   floating: Left -> MoveFloating, Right -> ResizeFloating(corner_for_press);
//   tiled: Left -> Tiling if tiling_drag.modifier (or from_titlebar && tiling_drag.titlebar), else None; Right -> ResizeTiled(edges_for_press)
pub fn drag_step(wm: &mut Wm, d: &mut Drag, x: i32, y: i32, now_ms: u64) -> bool   // applies the move; returns whether a re-arrange is needed
//   MoveFloating: floating_rect = start offset by (x-ox, y-oy) via on_floating_moved
//   ResizeFloating: resize_from_corner(start, corner, dx, dy, floating_minimum_size, floating_maximum_size)
//   ResizeTiled: only if now_ms - last_apply_ms >= 16: resize_edge(node, h, ±(x - last.x)), resize_edge(node, v, ±(y - last.y)) with sign = outward; last = (x,y)
//   Tiling: nothing (preview only)
pub fn finish_drag(wm: &mut Wm, d: &Drag, target: Option<DropTarget>)   // Tiling: wm.drop_window(d.node, &target)
// overlay.rs
pub struct Overlay; impl Overlay { pub fn show(&mut self, r: Rect, color: Color); pub fn hide(&mut self); }
//   class "i3win_drop", WS_EX_LAYERED|WS_EX_TRANSPARENT|WS_EX_TOOLWINDOW|WS_EX_TOPMOST|WS_EX_NOACTIVATE, alpha 128, color = client.focused indicator
```
