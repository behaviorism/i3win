**Goal:** Build `i3win-core`, a pure-Rust library holding the whole i3 brain (tree, config, keys, commands, all window-manager operations, layout geometry), fully unit-tested, with no Win32 dependency.

**Architecture:** An arena tree (`Tree`) of Root → Output → Workspace → Container → Window nodes. `Wm` owns the tree and config, mutates it in response to platform events and commands, and queues `Effect`s. `arrange()` turns the tree into concrete rectangles + decoration descriptions. Plans 2–4 build the Win32 platform, the bar and IPC on top of this crate.

**Tech Stack:** Rust stable 2021 edition, MSVC toolchain, `regex = "1"`.

**Spec:** `docs/superpowers/specs/2026-10-16-i3win-design.md`

**Sequence:** This is Plan 1 of 4. Plan 2 (platform + decorations), Plan 3 (bar + status), Plan 4 (IPC + i3win-msg) follow in that order.

### Task 4: The tree arena

**Files:**
- Create: `crates/core/src/tree.rs`; Modify: `lib.rs`

**Interfaces:**
- Consumes: `geom::{Rect, Orientation}`.
- Produces (all `pub`):
  - `#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, PartialOrd, Ord)] pub struct WindowId(pub isize);`
  - `#[derive(Clone, Debug, PartialEq)] pub struct WindowInfo { pub id: WindowId, pub title: String, pub class: String, pub instance: String, pub rect: Rect, pub wants_float: bool }` — `rect` is the window's current visible frame.
  - `#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, PartialOrd, Ord)] pub struct NodeId(pub u32);`
  - `#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Layout { SplitH, SplitV, Tabbed, Stacked }` with `orientation(self) -> Orientation` (SplitH, Tabbed → Horizontal; SplitV, Stacked → Vertical), `letter(self) -> char` ('H','V','T','S'), `as_str(self) -> &'static str` ("splith","splitv","tabbed","stacked").
  - `#[derive(Clone, Debug)] pub struct WindowData { pub info: WindowInfo, pub floating_rect: Option<Rect>, pub urgent: bool }`
  - `#[derive(Clone, Debug)] pub enum NodeKind { Root, Output { name: String, rect: Rect, scale: f32 }, Workspace { name: String, num: Option<i32> }, Container, Window(WindowData) }`
  - `#[derive(Clone, Debug)] pub struct Node { pub id: NodeId, pub kind: NodeKind, pub parent: Option<NodeId>, pub children: Vec<NodeId>, pub floating: Vec<NodeId>, pub focus: Vec<NodeId>, pub layout: Layout, pub percent: f64, pub fullscreen: bool }`
    - `children`: tiling children in visual order. `floating`: only used on Workspace nodes. `focus`: focus stack over `children ∪ floating`, most recent FIRST. For an Output, `focus[0]` is its visible workspace. For Root, `focus[0]` is the focused output.
  - `pub struct Tree { nodes: Vec<Option<Node>>, root: NodeId }` — node ids are never reused.
  - Methods on `Tree`:
    - `new() -> Tree` (creates Root, layout SplitH)
    - `root(&self) -> NodeId`, `get(&self, id) -> &Node`, `get_mut(&mut self, id) -> &mut Node`, `contains(&self, id) -> bool`
    - `new_node(&mut self, kind: NodeKind, layout: Layout) -> NodeId` — unattached, percent 1.0
    - `attach(&mut self, parent, child, index: Option<usize>)` — inserts into `parent.children` at index (None = end); sets child.parent; child.percent = 1/n; every other sibling's percent *= (n-1)/n; pushes child to the END of parent.focus.
    - `attach_floating(&mut self, ws, child)` — pushes onto `ws.floating` and to the END of ws.focus; sets parent.
    - `detach(&mut self, child)` — removes from parent's children or floating, and from parent.focus; renormalizes remaining tiling siblings so percents sum to 1 (divide each by their sum); child.parent = None.
    - `remove(&mut self, id)` — detach, then free it and all descendants (children and floating).
    - `parent(&self, id) -> Option<NodeId>`, `index_in_parent(&self, id) -> Option<usize>` (tiling index), `is_floating(&self, id) -> bool`
    - `ancestors(&self, id) -> Vec<NodeId>` (parent first, Root last)
    - `is_ancestor(&self, anc, id) -> bool` (strict)
    - `workspace_of(&self, id) -> Option<NodeId>` (self if it is a workspace), `output_of(&self, id) -> Option<NodeId>` (self if output)
    - `window_node(&self, w: WindowId) -> Option<NodeId>`, `window_id(&self, id) -> Option<WindowId>`
    - `windows_under(&self, id) -> Vec<NodeId>` — all Window nodes in the subtree (tiling children in order, then floating), self included if a window
    - `set_focused(&mut self, id)` — for each (parent, child) pair on the path from id up to Root, move child to the FRONT of parent.focus.
    - `set_focused_within(&mut self, id, stop: NodeId)` — same but stops after updating `stop`'s focus stack (used for "focus inside a non-visible workspace").
    - `focused_descendant(&self, id) -> NodeId` — follow `focus[0]` down until a node with empty focus.
    - `focused_tiling_descendant(&self, id) -> NodeId` — like above but at each step take the first focus entry that is a tiling child (skip floating); stop when none.
    - `cleanup(&mut self, id)` — while `id` is a `Container` with no children: remember parent, `remove(id)`, continue with parent. Never removes Workspace/Output/Root.
    - `wrap(&mut self, id, layout: Layout) -> NodeId` — creates a Container with `layout`, puts it in id's exact slot (same index, same percent, same position in parent.focus), then attaches id inside it (percent 1.0). Returns the container.
    - `swap(&mut self, a, b)` — exchange the slots of two tiling nodes (possibly in different parents). Percents stay with the slot; focus-stack entries are swapped too.
    - `describe(&self, id) -> String` — Window → its title; Container/Workspace → `"{letter}[{children joined by ' '}]"`; floating children are omitted. Example: `H[w1 V[w2 w3]]`.

### Task 5: Command language parser

**Files:**
- Create: `crates/core/src/command.rs`; Modify: `lib.rs`

**Interfaces:**
- Consumes: `geom::{Direction, Orientation}`, `tree::Layout`, `criteria::{Criteria, parse_criteria}`.
- Produces:

```rust
#[derive(Clone, Debug, PartialEq)] pub enum Toggle { Toggle, Enable, Disable }
#[derive(Clone, Debug, PartialEq)] pub enum WorkspaceTarget { Name(String), Number(i32), Next, Prev, BackAndForth }
#[derive(Clone, Debug, PartialEq)] pub enum OutputTarget { Dir(Direction), Name(String) }
#[derive(Clone, Debug, PartialEq)] pub enum SplitArg { Horizontal, Vertical, Toggle }
#[derive(Clone, Debug, PartialEq)] pub enum LayoutArg { Set(Layout), Default, ToggleSplit, ToggleAll }
#[derive(Clone, Debug, PartialEq)] pub enum Command {
    Exec(String),
    Focus(Direction), FocusParent, FocusChild, FocusModeToggle, FocusFloating, FocusTiling, FocusMatched,
    FocusOutput(OutputTarget),
    Move(Direction, Option<i32>),          // optional "N px" (floating only)
    MoveToWorkspace(WorkspaceTarget),
    MoveWorkspaceToOutput(OutputTarget),
    Workspace(WorkspaceTarget),
    Split(SplitArg),
    Layout(LayoutArg),
    Fullscreen(Toggle), Floating(Toggle),
    Kill,
    Resize { grow: bool, axis: Orientation, px: Option<i32>, ppt: Option<i32> }, // width = Horizontal
    Mode(String), Reload, Restart, Exit, Nop,
}
#[derive(Clone, Debug)] pub struct CommandGroup { pub criteria: Option<Criteria>, pub commands: Vec<Command> }
pub fn parse_commands(input: &str) -> Result<Vec<CommandGroup>, String>;
```

Parsing rules:
- Split on unquoted `;` into groups; each group may start with `[...]` criteria (passed to `parse_criteria` without brackets). Split the rest of the group on unquoted `,` into commands sharing that criteria. Empty segments are skipped. Quotes are `"` with `\"` escape; quoted tokens have quotes stripped.
- `exec [--no-startup-id] REST` — REST is the raw remainder of that comma segment, trimmed; if REST is a single quoted string, strip the quotes. Empty REST → Err.
- `focus` alone → `FocusMatched`. `focus left|right|up|down|parent|child|mode_toggle|floating|tiling`. `focus output left|right|up|down|NAME`.
- `move left|right|up|down [N [px]]`; `move [container|window] [to] workspace (number N | next | prev | back_and_forth | NAME...)`; `move workspace to [output] (left|right|up|down|NAME)`.
- `workspace [--no-auto-back-and-forth] (number N | next | prev | back_and_forth | NAME...)`. `NAME...` = remaining tokens joined by one space. `number N...`: N = leading decimal digits of the joined remainder (e.g. `3:www` → 3); no digits → Err.
- `split h|horizontal|v|vertical|t|toggle`.
- `layout stacking|stacked|tabbed|splith|splitv|default` or `layout toggle split` / `layout toggle all` / `layout toggle` (= all).
- `fullscreen` (= toggle) / `fullscreen toggle|enable|disable`; `floating toggle|enable|disable`.
- `resize grow|shrink width|height [N [px]] [or M ppt]`. If neither given: px=Some(10), ppt=Some(10). `resize set ...` → Err("unsupported").
- `mode NAME` (quotes stripped), `kill`, `reload`, `restart`, `exit`, `nop [anything]`.
- Unknown verb → `Err(format!("unknown command: {verb}"))`. Commands are case-sensitive.

Parsing rules:
- Strip a leading UTF-8 BOM; normalize `\r\n` → `\n`; join lines ending in `\` with the next line; trim each line; skip blank lines and lines starting with `#`. Tokens are separated by any run of spaces/tabs.
- `set $name value...` → variable. Before parsing every subsequent line, replace variables (longest name first).
- `bindsym [--whole-window|--release]... COMBO COMMAND...` → Binding (COMMAND = raw remainder). `--release` → warning + skip the line. Bad combo → warning + skip.
- `mode "NAME" {` ... `}` → bindings go to `bindings[NAME]`. Also accept `{` on the same line only (i3 requires it).
- `bar {` ... `}` block with nested `colors {` ... `}`. Keys: `position`, `status_command` (raw remainder), `font`, `height`, `workspace_buttons yes|no`; colors keys per BarColors (`background`/`statusline`/`separator` take 1 color, the `*_workspace`/`binding_mode` keys take 3). Unknown keys inside bar → warning.
- `font pango:Family Words Size` or `font Family Words Size` — last token is size (float); family = remaining words joined by space with `pango:` prefix removed. Unparseable size → warning, keep default.
- `exec`/`exec_always [--no-startup-id] cmd...` (raw remainder).
- `default_border normal [N] | pixel N | none` (also `new_window` as alias); `default_floating_border` same; `normal` without N = 2.
- `for_window [criteria] command...`; `assign [criteria] [→] [workspace] [number] NAME` (number form → `WorkspaceTarget::Number`, else `Name`).
- `workspace NAME output OUT [OUT...]` → workspace_outputs (NAME may be quoted).
- `gaps inner N` / `gaps outer N` (other gap forms → warning).
- `client.focused|client.focused_inactive|client.unfocused|client.urgent C C C [C [C]]`; `client.placeholder`/`client.background` → silently ignored.
- Everything else → warning `"line N: unknown directive: ..."` and skip. Never panic.

Behavior:
- **`new`**: create one Output node per OutputInfo (in order) under Root. For each output pick its initial workspace name: the first `config.workspace_outputs` entry listing this output's name whose workspace doesn't exist yet; otherwise the lowest positive integer not used as a workspace name. Root focus: first output.
- **`create_workspace(output, name)`**: `num` = leading decimal digits of name parsed as i32 (none → `None`); layout = `config.workspace_layout`; insert into `output.children` sorted by (num ascending with `None` after all numbers, then name); push to END of output.focus (i.e. not visible). Emit `Ipc(Workspace{change:"init", current: Some(name), old: None})`.
- **`insert_tiled(ws, node)`**: f = `tree.focused_tiling_descendant(ws)`. If f is a Window → attach to f's parent at f's index + 1. If f is a Container → attach to f at end. If f == ws → attach to ws at end.
- **`manage(info)`**: ignore if already managed. Target ws = first `config.assigns` whose criteria matches (class/instance/title) → resolve target name (Number(n): existing ws with num n, else name `n`; Name(s): s), find or create it on the focused output; else the focused workspace. Create Window node (`floating_rect: None`, `urgent: false`). If `info.wants_float`: floating_rect = `info.rect.centered_in(&output_rect)`, attach_floating; else `insert_tiled`. If target ws is the focused workspace: `tree.set_focused(node)` and push `Effect::Focus(id)`; otherwise `tree.set_focused_within(node, ws)`. Then for each matching `for_window`: parse it and `exec_command` each command with target = node (ignore errors, but keep going). Emit `Ipc(Window{change:"new", window})`.
- **`unmanage(id)`**: return if unknown. Remember ws, whether it was the globally focused node, and the parent. `tree.remove(node)`; `tree.cleanup(parent)` if parent is a Container. If ws is now empty (no children, no floating) and not visible → remove ws (emit `Workspace{change:"empty"}`). If it was focused: `f = tree.focused_descendant(ws)`; `tree.set_focused(f)`; if f is a window push `Effect::Focus`. Emit `Window{change:"close"}`.
- **`on_focus_changed(id)`**: unknown → ignore. If its workspace is visible: `tree.set_focused(node)`, clear its `urgent`, emit `Window{change:"focus"}` (no `Effect::Focus`, the OS already did it). If not visible: set `urgent = true` and push `Effect::Focus(current focused window)` if any (we refuse focus stealing; design call).
- **`on_title_changed`**: update `info.title`; emit `Window{change:"title"}`. **`on_floating_moved`**: if floating, set `floating_rect = Some(rect)`; ignore otherwise.
- **`run_command(input)`**: parse; on parse error return `vec![CommandResult{success:false, error:Some(e)}]`. Remember `focused_window()` before. For each group: targets = all window nodes matching criteria (tree order via `windows_under(root)`), or `[self.focused()]` without criteria. For each command, for each target: `exec_command`; one `CommandResult` per command (failure if any target failed; criteria matching nothing = success). Afterward, if `focused_window()` changed and is `Some`, push `Effect::Focus`.

### Task 8: Workspace and output operations

**Files:**
- Create: `crates/core/src/ops/workspace.rs`; Modify: `ops/mod.rs`, `wm.rs` (dispatch arms for `Workspace`, `MoveToWorkspace`, `MoveWorkspaceToOutput`, `FocusOutput`, and the `FocusMatched` workspace switch)

**Interfaces:**
- Consumes: `Wm` internals from Task 7.
- Produces (`impl Wm` in `ops/workspace.rs`):
  - `pub fn show_workspace(&mut self, ws: NodeId)`
  - `pub(crate) fn resolve_workspace(&mut self, t: &WorkspaceTarget) -> Option<NodeId>` — finds or creates (on focused output)
  - `pub fn switch_workspace(&mut self, t: &WorkspaceTarget) -> Result<(), String>`
  - `pub fn move_to_workspace(&mut self, target: NodeId, t: &WorkspaceTarget) -> Result<(), String>`
  - `pub fn move_workspace_to_output(&mut self, t: &OutputTarget) -> Result<(), String>`
  - `pub fn focus_output(&mut self, t: &OutputTarget) -> Result<(), String>`
  - `pub(crate) fn output_in_direction(&self, from: NodeId, dir: Direction) -> Option<NodeId>`
  - `pub fn set_outputs(&mut self, outputs: Vec<OutputInfo>)`
  - `pub(crate) fn sorted_workspaces(&self) -> Vec<NodeId>` — all workspaces, ordered by (num with None last, name)

Behavior:
- **show_workspace(ws)**: `old_global` = current focused workspace. `out` = output of ws; `old_vis` = visible ws of out. Move ws to front of `out.focus`; `tree.set_focused(tree.focused_descendant(ws))` (this also brings out to front of Root.focus). If `old_vis != ws` and old_vis is empty → remove it (emit `Workspace{change:"empty"}`). If `old_global != ws`: `prev_workspace = Some(name of old_global)` and emit `Workspace{change:"focus", current: ws name, old: old name}`. Also: if `old_global` is on another output and empty and no longer visible, remove it as well (it stays visible on its output, so normally nothing happens).
- **resolve_workspace**: `Name(s)` → find by name, else create on focused output. `Number(n)` → first ws in `sorted_workspaces` with num == Some(n), else create named `n.to_string()`. `Next`/`Prev` → neighbor of the focused ws in `sorted_workspaces`, wrapping; `None` if only one. `BackAndForth` → `prev_workspace` resolved as Name, or None.
- **switch_workspace**: resolve; None → Ok (no-op). `show_workspace`.
- **move_to_workspace(target, t)**: target is a Workspace → Ok no-op. Resolve dest (creating it doesn't show it). dest == source ws → Ok. Remember whether target was floating. Detach target; if old parent is a Container → cleanup. Into dest: floating → `attach_floating`, else `insert_tiled(dest, target)`. `tree.set_focused_within(focused_descendant(target), dest)`. If dest isn't visible, dest stays hidden. If the source ws is visible and was focused: `tree.set_focused(tree.focused_descendant(source))`. If dest is visible on another output, focus stays on source. Emit `Window{change:"move"}` for every window moved.
- **output_in_direction(from, dir)**: candidates = other outputs whose rect center lies strictly in `dir` from from's center (Left: cx < from.cx, etc.). Pick min by primary-axis distance, tie → smaller secondary-axis distance.
- **focus_output**: resolve (Dir or by name; not found → `Err("no such output")`); `tree.set_focused(focused_descendant(visible ws of it))`; emit `Workspace{change:"focus"}` if the focused ws changed (and update prev_workspace).
- **move_workspace_to_output**: ws = focused ws; dest resolved (Err if none, Ok no-op if same). If ws is the only workspace on its output: create a new workspace there named the lowest unused positive integer. Detach ws from source output; attach into dest keeping sort order (reuse the sorted-insert from create_workspace: factor it out as `pub(crate) fn attach_workspace_sorted(&mut self, output, ws)`). Source output: its focus stack now starts with its next workspace, which becomes visible. `show_workspace(ws)` on dest. Emit `Workspace{change:"move"}`.
- **set_outputs(new)**: match existing Output nodes by name. Update rect/scale of matches. For each new name: create Output (appended), initial workspace per the `new` rule. For each existing output not in the list: move all its workspaces to the first remaining output (`attach_workspace_sorted`, at END of its focus stack so they stay hidden; empty ones are removed instead); then remove the output node. If the focused output vanished, focus the first output's visible workspace. If `new` is empty, ignore the call (log is the platform's job).
- Workspace removal rule everywhere: a workspace is removed only when it is empty AND not visible.

### Task 10: Move in a direction

**Files:**
- Create: `crates/core/src/ops/movement.rs`; Modify: `ops/mod.rs`, `wm.rs` (arm `Move`)

**Interfaces:**
- Consumes: `output_in_direction` (Task 8), tree primitives.
- Produces: `impl Wm { pub fn move_direction(&mut self, target: NodeId, dir: Direction, px: Option<i32>) -> Result<(), String> }`

Algorithm (n = target):
1. n is a Workspace → Ok no-op.
2. n is floating: shift its `floating_rect` by `px.unwrap_or(10)` in dir; emit `Window{change:"move"}`; done.
3. Tiling. `cur = n`. Loop:
   - `p = parent(cur)`.
   - If `p.layout.orientation() != dir.orientation()`:
     - If p is a Workspace with ≤1 tiling child → go to the **Output step**.
     - If p is a Workspace with ≥2 tiling children → **re-orient the workspace**: create a Container with p's current layout, move all of p's tiling children into it (keep order and percents), attach it to p (percent 1.0), and set `p.layout` = SplitH (horizontal dir) or SplitV (vertical dir). Then `continue` without changing `cur` (the next iteration walks up through the new container to the now-matching workspace).
     - Else `cur = p; continue`.
   - Orientation matches. `i = index(cur)`; neighbor index = i+1 (forward) / i−1 (backward).
   - **cur == n** (n's own parent matches):
     - If the neighbor exists: if neighbor is a Window → `tree.swap(n, neighbor)`; done. If the neighbor is a Container → detach n, attach into the neighbor at index 0 (forward) or end (backward); cleanup the old parent; done.
     - If there's no neighbor: if p is a Workspace → go to "output". Else `cur = p; continue`.
   - **cur != n** (cur is an ancestor of n): detach n (remember old parent), attach to p at index(cur)+1 (forward) or index(cur) (backward; recompute the index after detaching); cleanup the old parent; done.
   - **Output step**: `o = output_in_direction(output_of(n), dir)`; None → Ok no-op. Else ws2 = visible ws of o; detach n, cleanup the old parent, attach into ws2 at index 0 (forward) or end (backward); `set_focused(n)`; emit `Workspace{change:"focus"}`; done.
4. Always finish with `tree.set_focused(n)` (focus follows the moved node) and emit `Window{change:"move"}` for n's windows.

### Task 11: Split, layout, resize

**Files:**
- Create: `crates/core/src/ops/layout_ops.rs`; Modify: `ops/mod.rs`, `wm.rs` (arms `Split`, `Layout`, `Resize`)

**Interfaces:**
- Produces (`impl Wm`): `pub fn split(&mut self, target: NodeId, arg: &SplitArg) -> Result<(), String>`, `pub fn set_layout(&mut self, target: NodeId, arg: &LayoutArg) -> Result<(), String>`, `pub fn resize(&mut self, target: NodeId, grow: bool, axis: Orientation, px: Option<i32>, ppt: Option<i32>) -> Result<(), String>`

Algorithms:
- **split(target, arg)**: new layout: Horizontal → SplitH, Vertical → SplitV, Toggle → the opposite of the parent's orientation (parent SplitV/Stacked → SplitH, else SplitV). Target is a Workspace → set its layout (only if it has ≤1 tiling child; otherwise Ok no-op). Target is floating → Ok no-op. Target is a Window: if its parent has exactly 1 tiling child → set the parent's layout; else `tree.wrap(target, layout)`. Target is a Container → set its layout. Focus stays on the target.
- **set_layout(target, arg)**: c = target if it is a Container or Workspace, else parent(target) (floating window → Ok no-op). `Set(l)` → l; `Default` → SplitH; `ToggleSplit` → SplitV if c is SplitH, else SplitH; `ToggleAll` → cycle Stacked→Tabbed→SplitH→SplitV→Stacked.
- **resize tiled**: find the nearest ancestor-or-self `c` of target (not going above the workspace's children) whose parent's layout is exactly SplitH (width) / SplitV (height) and whose parent has ≥2 tiling children. None → `Err("No container found to resize")`. delta = `ppt/100` if ppt is Some, else `px / output_width_or_height`. For shrink, delta = −delta. n = sibling count; `min = 0.05`. `new = c.percent + delta`; if `new < min` or `new > 1 − min*(n−1)` → `Err("cannot resize further")` with nothing changed. Scale the others: each other sibling s gets `s.percent * (1 − new) / (1 − old)`; if any would drop below min → Err and nothing changed. Then set c.percent = new.
- **resize floating**: d = px, or ppt% of the output width/height when px is None. Grow width: `w += d`, `x -= d/2`; shrink: the opposite, minimum w/h 50. Same for height with y/h.

Behavior:

### Task 13: Layout geometry (`arrange`)

**Files:**
- Create: `crates/core/src/arrange.rs`; Modify: `lib.rs`

**Interfaces:**
- Consumes: `Tree`, `Config`, `Wm::focused()`.
- Produces:

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum DecoState { Focused, FocusedInactive, Unfocused, Urgent }
#[derive(Clone, Debug, PartialEq)] pub struct Tab { pub title: String, pub state: DecoState, pub rect: Rect, pub node: NodeId } // node = the tab's child node (clicking the tab focuses it)
#[derive(Clone, Debug, PartialEq)] pub enum Deco {
    Frame { key: NodeId, rect: Rect, title_rect: Option<Rect>, border: i32, title: String, state: DecoState, floating: bool, above: WindowId },
    TabBar { key: NodeId, rect: Rect, vertical: bool, tabs: Vec<Tab> },
}
#[derive(Clone, Debug, PartialEq)] pub struct WindowPlacement { pub id: WindowId, pub rect: Rect, pub floating: bool, pub fullscreen: bool }
#[derive(Clone, Debug, PartialEq, Default)] pub struct Arrangement { pub windows: Vec<WindowPlacement>, pub hidden: Vec<WindowId>, pub decos: Vec<Deco>, pub fullscreen_outputs: Vec<String> }
pub fn title_height(font: &Font, scale: f32) -> i32;      // (size_pt*96/72*scale).round() + (8*scale).round()
pub fn bar_height(config: &Config, scale: f32) -> Option<i32>; // None if no bar; Some(height*scale rounded) if set; else title_height(bar font or main font, scale) + (2*scale).round()
pub fn arrange(tree: &Tree, config: &Config, focused: NodeId) -> Arrangement;
pub fn floating_frame_from_client(config: &Config, scale: f32, client: Rect) -> Rect; // inverse of the floating frame→client inset (step 5); used when the user drags a floating window
impl Wm { pub fn arrange(&self) -> Arrangement { arrange(&self.tree, &self.config, self.focused()) } }
```

Algorithm, per Output `o` (Root children, in order), with `ws = o.focus[0]`, `th = title_height(&config.font, o.scale)`:
1. `area = o.rect`; if `bar_height(config, o.scale) = Some(bh)`: Top → `area.inset(0, bh, 0, 0)`, Bottom → `area.inset(0, 0, 0, bh)`.
2. **Fullscreen**: if a window in ws (tiling or floating) has `fullscreen` → place it at `o.rect` (full output, bar not subtracted) with `fullscreen: true`, push `o`'s name to `fullscreen_outputs`, hide every other window of ws, no decos for ws. Skip to hidden-collection.
3. **Gaps**: `g = gaps_inner`, `out = gaps_outer`; `content = area.inset(out + g - g/2, out + g - g/2, out + g/2, out + g/2)`. Every tiled leaf frame is later inset by `(g/2, g/2, g - g/2, g - g/2)`. (With g = 0 and out = 0, nothing changes.)
4. **place(node, rect, in_tabs)** recursively, starting at `place(ws, content, false)`:
   - SplitH: n tiling children; child i gets width `(percent_i * rect.w as f64).round() as i32` for i < n−1; the last gets the remainder; x accumulates. SplitV is the same vertically.
   - Tabbed: header `Rect(rect.x, rect.y, rect.w, th)`; tab i width `rect.w / n`, last gets the remainder. Active child = first entry of node.focus that is a tiling child. `place(active, rect.inset(0, th, 0, 0), true)`. Every window under the other children → hidden. Push `Deco::TabBar { key: node.id, rect: header, vertical: false, tabs }`.
   - Stacked: header `Rect(rect.x, rect.y, rect.w, th*n)`; tab i = `Rect(rect.x, rect.y + i*th, rect.w, th)`; the active child goes in `rect.inset(0, th*n, 0, 0)`; `vertical: true`.
   - Empty workspace/container: nothing.
   - Window leaf: `frame = rect.inset(g/2, g/2, g - g/2, g - g/2)`. Border from `config.default_border`:
     - `Normal(b)`, not in_tabs: `title_rect = Some(Rect(frame.x, frame.y, frame.w, th))`, client = `frame.inset(b, th, b, b)`
     - `Normal(b)`, in_tabs: no title, client = `frame.inset(b, 0, b, b)`
     - `Pixel(b)`: no title, client = `frame.inset(b, b, b, b)`
     - `None`: client = frame, **no Frame deco**
     - Push `WindowPlacement { rect: client, floating: false, fullscreen: false }` and (unless None) `Deco::Frame { key: node.id, rect: frame, title_rect, border: b, title, state, floating: false, above: window id }`.
     - Gaps-inset note: inside a tabbed/stacked container only the leaf inset applies; the header itself isn't inset.
5. **Floating** windows of ws, in `ws.floating` order: frame = `floating_rect` (fallback `info.rect`); border from `config.default_floating_border`, same rules with in_tabs = false; Frame with `floating: true`.
6. **Hidden**: every window in every non-visible workspace, plus the ones hidden above. Order: tree order.
7. **Tab titles**: a Window child → its title; a Container child → `tree.describe(child)`.
8. **DecoState(c)**: F = focused node. `Urgent` if c or any window under c is urgent. Else `Focused` if c == F, c is an ancestor of F, or F is an ancestor of c. Else `FocusedInactive` if `parent(c).focus[0] == c`. Else `Unfocused`.

Order of `windows`/`decos`: outputs in order, then tiling depth-first in child order, then floating.
